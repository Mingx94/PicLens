## Adaptive-concurrency mechanism benchmark — 2026-07-18

An Intel Core i5-12400 run used 8,191 hard-linked paths to the same small PNG. Adaptive scheduling selected six workers. Cold/warm runs completed 663/1,042 visible-thumbnail requests in the settle window, with throughput of 400.1/630.8 requests per second, first-thumbnail latency of 166/156 ms, frame-interval p95 of 10.05/9.99 ms and peak working sets of 180,498,432/208,773,120 bytes.

A preceding four-worker sample completed 480/893 requests with frame-interval p95 of 11.02/11.40 ms and peak working sets of approximately 143/175 MiB. The comparison documented the mechanism's throughput improvement and memory cost, but repeated hard links and warm filesystem metadata did not represent heterogeneous decoder or storage performance.

## Small-fixture mechanism smokes

Two-image runs validated metrics plumbing、warm-cache behavior and startup-memory changes only. They were explicitly not representative performance evidence.

After embedded application fonts were removed, the recorded Release executable decreased from 55,243,537 to 5,327,267 bytes, and the two-image startup sample showed a substantially lower working set without increasing measured settle time.
