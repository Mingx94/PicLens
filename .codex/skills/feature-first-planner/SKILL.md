# Feature-First Planner

Start with one real user capability, not global navigation or an imagined complete application.

## Method

1. Name the user, trigger, desired outcome, required information, and primary action.
2. Define the smallest useful version that can be implemented and shipped independently.
3. Sketch the content and controls in grayscale. Defer fonts, icons, shadows, and decorative color until hierarchy works.
4. Identify only the states required for this increment: initial, working, success, empty, and likely failure states.
5. Flag speculative functionality as later work instead of implying it in the current UI.
6. Prefer a short design-build-use cycle over designing every feature and edge case in advance.

## Output

Provide a compact feature slice containing the user flow, content inventory, rough structure, required states, deferred ideas, and implementation acceptance criteria. Distinguish product decisions from visual decisions. Do not modify code when the user requested planning only.
