# UI Personality

Translate an intended product character into a small set of concrete visual and verbal decisions.

## Method

- Clarify the audience, context, trust level, and desired traits, such as formal, calm, playful, premium, or utilitarian.
- Inspect products familiar to the audience for category expectations, without copying a direct competitor.
- Recommend a typography direction, color mood, corner style, imagery character, and writing tone that reinforce the same traits.
- Check that radius, language, icons, and illustration style remain coherent across components.
- Prefer a neutral foundation when other elements already carry strong personality.

## Output

Produce a short personality statement, a trait-to-decision mapping, examples of suitable interface language, consistency risks, and a small do/don't list. Treat subjective options as options, not defects. Preserve an existing brand system unless the user asked to change it.
