# Component Rethink

Challenge a familiar component shape only when a different composition would improve comprehension or selection.

## Method

1. Identify the task, information relationships, scanning behavior, sorting needs, and interaction constraints.
2. Keep the native or conventional component when it already serves those needs.
3. Consider richer grouped menus, combined table fields, visual data, or selectable cards only when they expose useful context.
4. Preserve keyboard behavior, focus order, semantics, responsiveness, and expected interaction feedback.
5. Avoid custom controls that imitate native behavior incompletely.

## Output

Provide the current component's limitation, one minimal improvement, at most two meaningful alternatives, tradeoffs, and accessibility acceptance criteria. Do not redesign merely to appear novel.
