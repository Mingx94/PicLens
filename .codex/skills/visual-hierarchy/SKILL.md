# Visual Hierarchy

Make importance visible without making every important-looking element larger.

## Review

- Identify primary, secondary, and tertiary information before changing styles.
- First reduce competition from secondary elements; increase emphasis only when necessary.
- Balance font size with weight and contrast. Avoid illegibly small or light supporting text.
- Counterbalance visually heavy icons or shapes with lower contrast.
- Treat labels as supporting content unless users scan specifically for the label.
- Combine labels with values when natural language can communicate the relationship more directly.
- Keep semantic markup correct while styling headings according to the interface's visual hierarchy.

## Output

For each finding, name the competing elements, intended order of attention, smallest adjustment, and a scanability check. Preserve accessibility and content meaning; never hide necessary labels or headings merely for visual cleanliness.
